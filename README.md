Make.fun bounty entry: Office Artifacts: The One-Line Placard Contest. A program that writes a single-line museum placard for an ordinary office object — a stapler, treated as an ancient artifact dug from a lost civilisation — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The placard (126 characters):

> Stapler, c. 2004. Pressed steel, permanently jammed. Ritual binding device; donor unknown, last seen circling the photocopier.

## Self-test

```sh
python3 main.py --self-test --out-dir /tmp/office-artifacts-out
```
